# Repoverse — Orbital R

A custom R silhouette with a rising orbital cut through the bowl and stem. The cut is transparent, so the mark works in one color on dark, light and accent backgrounds.

- Primary vector: ../public/brand/repoverse-mark.svg
- Vector wordmark lockup: ../public/brand/repoverse-lockup.svg (outlined lettering; no font dependency)
- Transparent PNG: repoverse-mark.png (1024 × 1024)
- Dark-on-light vector: mark-light.svg
- Blue vector: mark-blue.svg
- Identity preview: identity-board.png

Keep the original proportions. Minimum displayed mark box: 16px; normal app size: 27px. Reserve at least one stem-width of clear space. No glow, bevel, extra orbit or code brackets are needed. The React component inherits its surrounding text color and uses per-instance mask IDs.

The app header, loader and error page share BrandMark. Browser and Apple touch icons use the same geometry. The 15-second film uses the new primary mark.
